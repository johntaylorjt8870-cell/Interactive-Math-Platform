# قاعدة الاتجاه: العربية RTL والرياضيات LTR دائمًا

> الواجهة عربية (`dir="rtl"`)، لكن **كل تعبير رياضي يجب أن يُعرض داخل عازل LTR**.
> مخالفة هذه القاعدة تعكس الترتيب بصريًا، فيقرأ الطالب معادلة مقلوبة.

## القواعد السبع

### 1) الرياضيات تُمرَّر عبر مكوّنات، لا كنص حرّ

| الحالة | المكوّن |
|---|---|
| تعبير رياضي كامل (صيغة، معادلة، متباينة) | `<MathExpr value="…" display />` |
| كسر مكدّس | `\frac{…}{…}` داخل `MathExpr` |
| رياضيات داخل جملة عربية | `<RichText text="… $x+1$ …" />` |
| نص عربي فيه كلمة لاتينية | `<LatinRuns text="…" />` |
| رمز داخل شكل هندسي | يُرسم تلقائيًا داخل `Figure` |

**لا تكتب رياضيات مباشرة داخل JSX** ولا داخل نص عربي بلا `$...$`.

### 2) كل رياضيات داخل نص تُكتب بين `$...$`

```tsx
<RichText text="المعادلة $2x + 3 = 11$ حلها $x = 4$." />
```

- ما بين `$` → `MathExpr` (LTR معزول + كسور مكدّسة).
- ما خارجها → `LatinRuns` (عربي RTL مع عزل المقاطع اللاتينية المتصلة).

التدقيق الآلي (`npm run audit:lesson`) **يرفض** أي أمر LaTeX خارج `$...$`،
لأنه سيظهر للطالب كنص خام.

### 3) عزل المقاطع لا الكلمات

ممنوع تقسيم عبارة لاتينية إلى كلمات معزولة (`split(/\s+/)` ثم تغليف كل كلمة) —
هذا يعكس الترتيب حتمًا. يُعزل المقطع المتصل كوحدة واحدة. `LatinRuns` تفعل ذلك.

### 4) الكسور مكدّسة دائمًا

```txt
صحيح:  \frac{1}{2}      ← بسط فوق مقام وخط كسري
خطأ:   1/2              ← كسر مسطّح يُرفض في التدقيق
```

### 5) الاتجاه يُفرض بـ `isolate` لا `embed`

`globals.css` تستخدم `unicode-bidi: isolate` على `[dir="ltr"]` و`.ltr-run`
وكل أصناف الرياضيات؛ و`embed` أضعف ولا يمنع تفاعل الأرقام المجاورة مع سياق RTL.

### 6) داخل SVG

- SVG نفسه لا يتأثر بـ RTL، لكن كل نص داخله يُحدَّد صراحةً:
  - رموز رياضية: `<text direction="ltr">` بخط الرياضيات.
  - كلمات عربية: `<text direction="rtl">` بخط Cairo.
- الأشكال تُبنى في **فضاء إحداثيات رياضي (y للأعلى)**، والقلب إلى فضاء SVG
  يحدث في نقطة واحدة (`toSvg`) — فلا تتفرّق حالات القلب وتتناقض.

### 7) جداول واتجاه الخلايا

الجداول RTL بطبيعتها؛ الخلايا التي تحوي رياضيات تُغلف بـ `$...$` داخل `RichText`.

## الفحص قبل الدمج

```bash
npm run check:math-direction   # يفحص CSS والعزل وممنوعات الكسور المسطّحة
npm run self-test              # يفحص المحلّل والتطبيع والهندسة وقواعد التدقيق
npm run verify                 # كل البوابات + البناء
```

## أمثلة صحيحة

```tsx
import MathExpr from "@/components/math/MathExpr";
import RichText from "@/components/bidi/RichText";

// صيغة بارزة:
<MathExpr value="\frac{a}{b} \times \frac{c}{d} = \frac{a \times c}{b \times d}" display />

// رياضيات داخل شرح:
<RichText text="لوحّدنا المقامين: $\frac{1}{2} + \frac{1}{3} = \frac{5}{6}$." />

// رمز في جدول الرموز:
<MathExpr value="\perp" />
```

## حالات مقصودة ليست أخطاء

- كلمة لاتينية واحدة داخل نص عربي (`Subject`, `x`) — آمنة لأنها مقطع واحد.
- أرقام داخل نص عربي (`2 مثال`) — تُعرض RTL بشكل صحيح في الجملة.
- `\text{سم}` لجعل وحدة عربية داخل تعبير رياضي — مدعومة وتُعزل RTL داخل الرياضيات.
