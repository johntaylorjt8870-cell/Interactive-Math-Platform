> لكل درس ملف `coverage.json` في مجلده:
> `src/lessons/<lesson-id>/coverage.json`
>

## معنى الحقول

| الحقل | المعنى | كيف يُتحقق منه آليًا |
|---|---|---|
| `lessonId` | يجب أن يطابق مجلد الدرس ومعرّف المنهاج | مقارنة مباشرة |
| `textbook.title` | عنوان المصدر | يجب أن يطابق `textbook.title` في المحتوى |
| `units[].body` | **النص الكامل** للقسم من الكتاب | يجب أن يظهر كاملًا في محتوى الدرس (بعد تطبيع الفراغات) |
| `units[].stepId` | معرّف الخطوة التي تعرض القسم | للمراجعة البشرية |
| `counts.steps` | عدد الخطوات | مطابقة فعلية |
| `counts.bookExamples` | عناصر `provenance: "book"` | مطابقة فعلية |
| `counts.extraExamples` | عناصر `provenance: "extra"` | مطابقة فعلية |
| `counts.misconceptions` | كتل الأخطاء الشائعة | مطابقة فعلية |
| `counts.guidedSolutions` | الحلول الموجّهة (`WorkedSolution`) | مطابقة فعلية |
| `counts.figures` | الأشكال الهندسية | مطابقة فعلية |
| `counts.checks` | التفاعلات التعليمية | مطابقة فعلية |
| `counts.fractions` | عدد `\frac` الفعلي في كل الدرس | مطابقة فعلية |

> **كل** حقل في `counts` إلزامي: التدقيق يرفض السجل الذي لا يعلن عددًا.

## كيف يُبنى السجل عمليًا

1. خُذ صفحات الكتاب، وقسّمها إلى أقسام كما يراها المؤلف (① ② ③ …).
2. لكل قسم: انسخ **نصّه الكامل** في `body` (لا تلخّصه هنا — هذا هو المرجع).
3. اكتب في `stepId` الخطوة التي تعرضه فعلًا في الدرس.
4. املأ `counts` من الدرس بعد الانتهاء.
5. شغّل:

```bash
npm run audit:lesson -- <lesson-id>
```

## كيف يُقرأ الفشل

| الرسالة | المعنى | الإصلاح |
|---|---|---|
| `نصوص مصدر غير موجودة كاملة في الدرس: ③` | قسم من الكتاب لم يظهر بنصه الكامل | أعِد النص كما هو (لا إعادة صياغة ولا اختصار) |
| `العدد غير مطابق لـ fractions` | أعداد السجل لا تطابق المحتوى | صحّح العدد أو المحتوى |
| `عناصر إضافية بلا سبب` | `extra` بلا `reason` | اكتب سبب الإضافة |
| `عناصر من الكتاب بلا مرجع` | `book` بلا `bookRef` | اكتب مرجع الصفحة/المثال |
| `خطوة حلّ بلا تعليل` | `why` فارغ | اكتب التعليل الرياضي |
| `كسور مسطّحة` | `1/2` بدل `\frac{1}{2}` | استخدم `\frac` |
| `أوامر LaTeX مجهولة` | أمر غير مدعوم | استخدم أمرًا مدعومًا أو صِف بالعربية |
| `رياضيات في نص غير مغلّفة بـ $...$` | LaTeX سيظهر خامًا | غلّفه بـ `$...$` |
| `مراجع إلى نقاط غير موجودة` | شكل يشير إلى نقطة غير معرّفة | صحّح معرّفات نقاط الشكل |
| `تحمل إجابات` | سؤال طالب فيه `answer`/`why` | انقل الإجابة إلى `src/content/teacher/**` |
