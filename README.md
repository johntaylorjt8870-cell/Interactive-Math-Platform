# منصة الرياضيات — الصف الثامن الإعدادي (سوريا)

منصة تعليمية تفاعلية لمنهاج الرياضيات للصف الثامن الإعدادي — الجبر والهندسة.

## التقنيات

- Next.js 16 (App Router) + React 19 + TypeScript (strict)
- Tailwind CSS v4
- PostgreSQL + Drizzle (يُستخدم حاليًا لفحص الصحة `/api/health` فقط)

## التشغيل

```bash
npm install
npm run dev        # http://localhost:3000
```

## البوابات (يجب أن تنجح قبل أي دمج)

```bash
npm run verify
```

تشمل: `lint` → `typecheck` → `check:math-direction` → `self-test` → `audit:lessons` → `build`.

| الأمر | وظيفته |
|---|---|
| `npm run lint` | ESLint (Next core-web-vitals) |
| `npm run typecheck` | TypeScript بلا إصدار ملفات |
| `npm run check:math-direction` | قواعد الاتجاه والعزل ومنع الكسور المسطّحة ومنع iframe |
| `npm run self-test` | اختبارات المحلّل الرياضي والتطبيع والتصحيح والهندسة **وقواعد التدقيق نفسها** |
| `npm run audit:lesson -- <lesson-id>` | تدقيق التغطية والمصدر والتعليل والأشكال لدَرس |
| `npm run audit:lessons` | تدقيق كل الدروس المنفَّذة (وعندما يكون السجل فارغًا يُدقَّق نموذج العرض التقني) |
| `npm run audit:fixture` | تدقيق نموذج العرض التقني وحده — يتحقق من أن خط التدقيق يعمل |

## بنية المشروع

```text
src/
  app/                 الصفحات ومسار الدرس وأدوات الـ API
    lesson/[id]/       صفحة الدرس: تعرض LessonShell للدروس المنفَّذة أو «قريبًا»
    api/grade/         تصحيح إجابات الطالب على الخادم
    api/teacher-key/   مفتاح المعلم الكامل (بعد كلمة المرور)
    dev/lesson-shell/  معاينة هيكل الدرس (تطوير فقط، 404 في الإنتاج)
  components/
    lesson/            هيكل الدرس: الشريط الجانبي، عرض الخطوات، الكتل، الحلول
    interactive/       الأنشطة التفاعلية (جرّب بنفسك، أين الخطأ، …)
    assessment/        الاختبار الختامي + فضاء المعلم
    math/              محلّل وعارض الرياضيات (كسور مكدّسة)
    geometry/          أشكال هندسية مبنية على إحداثيات
    bidi/              عزل الاتجاه (LatinRuns / RichText)
  content/
    types.ts           نموذج المحتوى v1 (المصدر، الخطوات، الكتل، الأشكال)
    teacher/           إجابات المعلم — خادمية فقط (server-only)
  data/curriculum.ts   بيانات المنهاج (المعرّفات والترتيب — لا تُغيَّر)
  lessons/registry.ts  سجل الدروس المنفَّذة (فارغ عمدًا حتى أول درس)
  lib/                 التقدّم، تطبيع الأجوبة، التصحيح
  dev/                 نموذج عرض تقني (ليس محتوى منهجيًا)
scripts/               بوابات الجودة: الاتجاه، الاختبار الذاتي، تدقيق الدروس
docs/                  قواعد الاتجاه، معيار الدرس، معجم المصطلحات، قالب التغطية
scripts/               أدوات الفحص والتدقيق والاختبار الذاتي
```

## إضافة درس

انظر `LESSON_WORKFLOW.md` — العملية كاملة في سبع خطوات.

## المبادئ الملزمة

1. كتاب الرياضيات مصدر مرجعي للمحتوى والترتيب.
2. الشرح يتوسّع ولا يُختصر الكتاب، ولا يُنسب محتوى مُخترع إلى الكتاب.
3. كل عنصر يحمل `provenance` (`book` مع `bookRef` / `extra` مع `reason`).
4. كل درس له `coverage.json` + تدقيق آلي.
5. أشكال الكتاب تُعاد بناؤها هندسيًا بدقة (إحداثيات وعلامات مشتقّة).
6. أسئلة الطالب لا تحمل حلولها؛ حلول المعلم خادمية فقط ولا تدخل حزمة المتصفح.
7. العربية RTL والرياضيات LTR معزولة، والكسور مكدّسة.
8. معرّفات الدروس وترتيبها ثابتة.
9. البوابات الآلية حدّ أدنى للجودة؛ الجودة التربوية تُراجع يدويًا.
